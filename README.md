# Marklister

Marklister is a Tampermonkey userscript for florr.io that allows you to create and manage a personal marklist.

## Features

- Add players to your personal marklist
- Add players by typing their name or clicking them in-game
- Add a reason for each marked player
- Edit or remove marklist entries
- Highlight marked players in-game
- Hitbox-based player tracking
- Persistent online storage

## Installation

1. Install the Tampermonkey browser extension.
2. Download `marklister.user.js`.
3. Open the downloaded file with Tampermonkey.
4. Click Install.
5. Open florr.io.

No additional server or software installation is required.

## Controls

- `Ctrl + D` — Toggle Display Lister
- `Ctrl + S` — Show Marklist
- `Ctrl + A` — Add Marklist
